# DeKa

NAMA KELOMPOK : DeKa

ANGGOTA KELOMPOK : 1. Arifah Khansa Aulia
                   2. Devika Radithya Padmarini
                   
DeKa adalah platform yang menawarkan jasa sewa penggunaan Samsung Tab. Dengan adanya program SDLS di Thursina IIBS, para santri diwajibkan menggunakan Samsung Tab sebagai device utama mereka. Namun, banyak orang tua santri kelas 11 merasa keberatan dengan kebijakan baru tersebut, karena kurangnya efisiensi dan kemudahan dalam mengerjakan tugas serta project sekolah dengan Samsung Tab. Oleh karena itu DeKa hadir sebagai solusi. Dengan DeKa, santri bisa menyewa Samsung Tab untuk digunakan dalam proses pembelajaran tanpa perlu emngganti device mereka.
